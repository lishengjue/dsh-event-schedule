这是一个由大一新生用DeepSeek HARNESS写的事件安排插件。希望大家能够积极指出bug,提交修改建议。

给 DeepSeek Harness 桌面版加的日历面板：月历 / 周时间线 / 每日三视图，支持单日、多日、每周重复事项与打钩完成，可从 .ics/.csv/.json 导入日程。

A calendar panel for DeepSeek Harness: month grid, week timeline and daily view, with repeating events, check-off, sticky notes, restore points, and .ics/.csv/.json schedule import.
